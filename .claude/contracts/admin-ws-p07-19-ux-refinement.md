# Task Contract: P07-19 Admin UX refinement — own root layout, top bar, `AdminPageHeader`, sidebar polish
- Class: L (route-tree change, one PR) · Branch: `feat/admin-ux-refinement` · Depends on: P07-10 merged (PR #116, #119), ADR 0023 Accepted (owner, 2026-11-17) · Must land **before** P07-11 · Index: [admin-workspace-index.md](admin-workspace-index.md)
- Desired outcome: the admin area looks and behaves like one workspace in the brand's style, apart from the visitor site: no public header, nav or footer; a slim top bar, one sidebar, one compact page header; the sidebar no longer slides under a sticky header.
- Scope IN: move `src/app/[locale]/admin/**` → `src/app/(admin)/[locale]/admin/**` (git mv, URLs unchanged); new admin root layout `src/app/(admin)/[locale]/layout.tsx` and one admin `not-found`; `src/app/fonts.ts` shared by both root layouts; admin top bar (brand, "View site", `LocaleSwitcher`, handle + role, sign-out); `AdminPageHeader` used by every admin page; sidebar polish (below); breadcrumb kept; the Overview group folded into one top link; distinct h1/`<title>` per page (users page "Người dùng"/"Users"); remove the duplicate signed-in/sign-out row from `AdminConsole`; one CSS variable `--admin-bar-h`.
- Scope OUT: routing/`pathnames`, `requireStaff`, RBAC, APIs, data, dashboard cards (P07-11), new screens, any change to a public page or to `SiteHeader`/`SiteFooter`/`MainNav`/`AccountMenu`, new dependencies or icon sets, Phase 10, a dark theme.
- Evidence: `src/app/[locale]/layout.tsx` (owns `<html>`, `SiteHeader`, `<main>`, `SiteFooter`); `src/app/[locale]/admin/layout.tsx` and `src/components/admin/admin-sidebar.tsx` (P07-10); `src/components/layout/{page-header,locale-switcher,site-header}.tsx` (`SiteHeader` is `sticky top-0 h-(--header-h)`); `src/app/globals.css:102-107` (`--header-h`); `src/components/admin/admin-console.tsx:186-208` (sign-out); `tests/{admin-portal,runbook,design-tokens,home-page-boundary,header-account}.test.ts`; P07-10 review findings (sticky offset bug, 1.09:1 active chip, 263px hero, double navigation, duplicate titles).
- Interface contract: no API, type or data change. New internal components only: `AdminTopBar` (server), `AdminSignOut` (client, same `DELETE /api/planner/session` call as the console), `AdminPageHeader` (server: `title`, `description?`, `actions?`).
- Design (frontend role, existing tokens only):
  - Top bar: `h-(--admin-bar-h)` (3.5rem), sticky, `bg-surface`, bottom hairline, `Container`-free full width with 16/24px gutters; brand "Chuyện Nhà Hưng · Quản trị" links to `/admin`; right side: "View site" (`/`), `LocaleSwitcher`, handle and role label, sign-out. On <768px the bar keeps brand + one Menu button; account actions move into the menu panel.
  - Sidebar: sticky at `top-(--admin-bar-h)`, `max-h` of the remaining viewport with `overflow-y-auto`; 12rem from `md`, 16rem from `xl`; rows 40px on desktop and 44px on touch; active item = 3px `primary` left bar + `surface-muted` background + weight 600 + `primary-strong` text (never colour alone); groups separated by whitespace and one hairline; Overview is a single top link, not a group of one.
  - Page header: compact row (h1 `text-2xl`/`md:text-3xl`, description one line, actions slot right on ≥`md`, stacked below), hairline bottom, 24px vertical padding; the breadcrumb sits above it inside `<main>`.
  - Surfaces: page `background`, sidebar and top bar `surface`, cards unchanged; type stays Lora for h1 only, Be Vietnam Pro elsewhere.
- Files allowed — **original proposal**: `src/app/(admin)/[locale]/admin/**` (the moved pages and layout, all nine `page.tsx` swapping `PageHeader` → `AdminPageHeader`), `src/components/admin/admin-sidebar.tsx`, new `src/components/admin/{admin-top-bar,admin-sign-out,admin-page-header}.tsx`, `messages/*.json`, `src/app/globals.css` (one variable), `docs/features/admin-shell.{md,vi.md}`.

  5. `docs/adr/0023-*` (status → Accepted), `docs/adr/README.*`, `docs/architecture.*`, `docs/features/{admin-shell,admin-portal,admin-content-cms,admin-runbook,community-trips}.*` and `.claude/context/project-context.md`: path mentions and one new paragraph.

  7. Later contracts P07-11…17 are **not** edited; the index carries the path mapping.
- Acceptance:
  - Spike first: `npm run build` accepts `app/(admin)/[locale]` beside `app/[locale]`; unknown admin URLs and forbidden roles both render the admin 404. If not, stop and ask (fallback in ADR 0023 needs the owner's yes).
  - Every URL returns the same status per role as on `main` (anonymous → sign-in with `returnTo`, member/editor 404 as before, `returnTo` allow-list unchanged); temporary-password redirect works.
  - No public header, nav, footer, public skip link or `/api/planner/session` account fetch on any admin page; public pages render byte-for-byte as before apart from the font import (diff of `/`, `/stories`, `/sign-in` HTML ignoring build ids).
  - **375px**: top bar = brand + Menu (44px); menu panel holds the groups, language, View site, handle, sign-out, `aria-expanded`/`aria-controls`, closes on navigation and on Escape; no horizontal scroll; page header stacks; content starts within 200px of the top.
  - **768px**: persistent 12rem sidebar; top bar shows account actions; page header actions inline; tables scroll inside their own container, never the page; no horizontal page scroll.
  - **1280px**: 16rem sidebar, sticky below the bar, never hidden under it, scrolls itself if taller than the viewport; content max-width unchanged; page header ≤ 120px tall.
  - Active item has a non-colour cue (bar + weight) and ≥3:1 contrast for the bar; text contrast ≥4.5:1; visible focus ring on every control; keyboard: skip link → top bar → sidebar → main; one `<h1>`, one `<main>`, one `nav` per purpose with distinct labels.
  - Each admin page has a distinct `<title>` and h1.
